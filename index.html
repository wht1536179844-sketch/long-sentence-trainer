核心痛点 不认识单词，凭什么知道谁是谓语？

英文长难句就像一个陌生城市：你不用认识每一栋楼叫什么名字，只要看懂路牌和制服，就能分清谁是大老板（主句谓语）、谁是小弟（从句/非谓语）。

1. 找“保镖词”（最稳）

看到它们，它们自己或后面紧跟的词几乎 100% 是谓语：

am / is / are was / were have / has / had will / would / can should / must

2. 见 to 就砍（最爽）

只要看到 to + 单词（如 to evade, to pass），它叫不定式（非谓语），绝对不是谓语，直接划掉！

3. 看动词小尾巴

不认识词义也能猜出它是动词：

-ed -ought / -aught -ize / -ate / -ify

注意：光棍 -ing（前无 be）和光棍 done（前无 be/have）都不是谓语！

4. 认“帽子词”（分主从）

看到它们说明后面要进“小弟从句”了，离它最近的那个谓语是从句谓语：

that which who / whom when / where because / although

盲猜演练 就算生词全打码，你也能找出主句谓语！

把实词全替换成 [生词]，只靠信号灯也能找到大老板：

That the [名] [生词]-ed to [生词] [生词]-s was [生词]-ed.
1. 看到 to [生词] → 见 to 就砍，划掉！
2. 看到句首有帽子词 That，紧跟它后面的 [生词]-ed 是从句小弟。
3. 看到保镖词 was → 剩下的 was (+ -ed) 就是主句大老板！

随身口袋卡 长难句高频路标词

👑 常见“保镖词”（必有谓语）

看到这些词，它自己或紧跟它的动词就是谓语：

am / is / are was / were have / has / had do / does / did will / would can / could may / might should / must

🎩 常见“帽子词”（从句开头）

看到它们，后面的第一个谓语通常是从句小弟：

that which who / whom / whose what whether / if when / while / as where because / since although / though

❌ 3 种“假谓语”（直接划掉）

它们长得像动词，但在句子里不能当老大：

  • to do（前面带 to）
  • 光棍 doing（前面无 be）
  • 光棍 done（前面无 be / have）

✂️ 并列“剪刀词”

遇到连接两个完整句子的 , and / , but，直接把它们当成句号剪成两半，分开找老大！
