# 长难句划分每日训练营 (Long Sentence Trainer)

专为英语语法零基础/四六级考研备考设计的纯前端互动练习网站：

1. **信号灯识词法**：不认识生词也能通过“保镖词 / 见 `to` 就砍 / 动词小尾巴 / 帽子词”定位谓语。
2. **4 步切句动画演示**：手把手拆解主句谓语与从句。
3. **每日划句闯关（12 题）**：支持本地自动记录连续打卡天数与通关进度。
4. **高频不规则过去式闪卡（24 词）**：专治 `bought / chose / thought` 等不加 `-ed` 的动词过去式。
5. **随身口袋卡**：高频保镖词、帽子词、假谓语速查。
