# 7 天看懂四级句子 · 零基础冲刺训练营

专为“基础薄弱 + 急需在一周左右看懂四级句子”设计的递进式实战网站：

- **7 天层层递进（Day 1 → Day 7）**：从 5 词短句起步，依次攻克介词短语、后置修饰（“……的”倒装）、被动/非谓语小尾巴、“大纸箱”从句、连词剪刀，直到 Day 7 全真四级长难句。
- **555 个高频救命词**：每天约 80 词，支持**一屏列表（可遮住中文自测）**与**翻卡记忆**双模式，自带浏览器语音朗读与不规则过去式/过去分词标注。
- **42 句实战拆句 + 全句点词词典**：句子里**任意单词点一下立即出中文意思与发音**，支持对比「极简主干」、手动括号切分与逐块中文语序对齐。
